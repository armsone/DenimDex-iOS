## Errors and resolutions

- Gemini was unavailable because its quota resets later; the assignment moved once to Claude Fable, which completed Android implementation.
- The Android public release APK could not replace the locally installed debug-signed app. The public APK kept the established release certificate, while matching debug builds replaced both device installs with data preserved.
- The Android signing password was exposed in a local tool log during signing recovery. It was immediately rotated in place, the old value marked superseded, and CodexPass updated. The signing certificate and update compatibility did not change.
- Android runtime screenshot attempts returned black/off-display captures, so they were not accepted as Matchup evidence and are not included in the repository.
